# 高频问答速查

跨模块抽题；细节回对应域正文。

**入口和 Agent 谁先谁后？**  
lifespan 预热池 → 请求 `get_session` 装配或复用图 → `astream`。见 01、02、03。

**SSE 有哪些事件？**  
thinking / phase / todo_update / token / tool_* / agent_dispatch / review_result / interrupt / done。见 01/02。

**为什么 Motor 还要 pymongo？**  
展示集合异步；LangGraph Saver/Store 同步。见 01/01、02/01。

**Harness 四阶段谁写？**  
`HarnessPhaseMiddleware` 钩子写 `state.phase`。见 03/02。

**什么时候开 grader？**  
state 留下非空 rubric；闲聊/纯定义句清空。见 03/02。

**子 Agent 看见父对话吗？**  
看不见；只见 enrichment 后的 description。见 04。

**MCP 挂了还能聊吗？**  
能，工具列表为空，本地工具仍在。见 05。

**图画在哪？**  
沙箱 matplotlib；下载走 `download_sandbox_file` + `/api/download`。见 06、01。

**三层记忆？**  
HOT=checkpoint，WARM=注入 brief，COLD=`read_memory`。见 07。

**重建沙箱为什么 Agent 不用重建？**  
工具拿的是 Proxy，Manager 只换底层容器并 bootstrap。见 08、03。

**Skills 怎么进容器？**  
bootstrap 拷仓库包；用户包 Store restore + sync 中间件。见 09。
